アルティメット・メトロノーム

マルチ機能 ポリリズム・メトロノーム 利用ガイド

1. 基本操作（START/STOP・BPM・マスターボリューム・TAP TEMPO）
START / STOP

左上の大きなボタンで再生・停止を切り替えます。初回起動時はブラウザのオーディオ制限解除のため一瞬だけ処理が入りますが、以降は即座に反応します。停止すると全ビジュアライザーがリセットされます。

BPM（テンポ）

10〜400 BPM の範囲で設定できます。スライダーで大まかに動かし、右の数値ボックスで1BPM単位の微調整が可能です。BPM左横に表示される速度標語テキスト（例：Allegro）をクリックすると速度標語から指定できるポップオーバーが開きます。

マスターボリューム

全体の音量を一括管理します（-40dB〜+6dB）。スライダーを一番左（-40dB）にするとマスターミュートになります。各トラック音量やサブディビジョン音量のバランスを保ったまま全体を絞るときに使います。

TAP TEMPO

曲のリズムに合わせて「TAP TEMPO」ボタンを2〜4回叩くと、その間隔から自動的にBPMを算出して反映します。ボタンが黄色にフラッシュして視覚的にも確認できます。

2. リズム同期モード（ポリリズム vs ポリメーター）

複数トラックを同時に鳴らす際の時間軸の同期方式を選択します。どちらのモードでも、上部のBPMが「4分音符の基準速度」となります。

小節同期モード（ポリリズム）

1小節の絶対的な長さを全トラックで揃えます。

「4拍」と「3拍」のトラックを同時に鳴らすと、小節の先頭（1拍目）が常に一致するクロスリズムになります。各拍の間隔はトラックによって異なるため、3対4のポリリズムを手軽に体験できます。

独立テンポモード（ポリメーター）

分母（音符の長さ）を固定し、各トラックが独自の拍数でループします。

「4拍」と「3拍」を分母4（4分音符基準）で鳴らすと、1拍の速さは同じですが小節の頭が周期的にずれていきます。特定の拍数が経過した後に再び揃う変拍子フレーズの練習に最適です。

3. リズムトラック設定（最大4トラック） コア機能

「+ トラック追加」ボタンで最大4つのリズムトラックを重ねられます。各トラックは独立して以下を設定できます。

設定項目 機能と操作方法
分子 / 分母 分子：1ループ内の拍数（1〜32）。
分母：基準となる音符の長さ（1〜32）。独立テンポモードでは、分母の値が拍の速さに直結します（例：8を選ぶと8分音符1個ぶんの長さが1拍になります）。
音程（1拍目 / 通常 / 裏拍） 3つのセレクトボックスで音程（C3〜C6）を指定します。
  • 左：1拍目（アクセント）の音程
  • 中央：2拍目以降の通常拍（1拍目より音量が自動で約40%減衰）
  • 右：裏拍（アップビート）の音程。「裏拍」スイッチがONのときのみ発音
音量 / 音色 / クリック 音量スライダー：トラックの音量を-40dB（ミュート）〜+15dBで調整します。スライダーと右の数値ボックスが連動します。
音色：サイン（丸くマイルド）・三角（中間）・矩形（鋭くクリアー）の3種類。
クリック：このトラックに重ねるサブディビジョン系クリック音の種類を選択します（4分／8分／16分／3連符／シャッフル／スキップ）。サブディビジョンセクションで設定した音程・音色がそのまま使われます。
裏拍（スイッチ） ONにすると各拍のちょうど半分のタイミングで裏拍音を挿入します。シンコペーションの練習に。音程は「音程」欄の右セレクトボックスで設定します。
リズムトレーナー 「鳴（発音）小節数」と「消（消音）小節数」のサイクルを繰り返す自動消音機能です。ONにするとメトロノームなしで続きのリズムをキープする耳トレ・キープ力トレーニングができます。
⚠ いずれか1トラックでもONの間は「サブディビジョン・ボリューム」セクションのフェーダーが全てロックされ、サブディビジョン音は強制消音されます。
4. サブディビジョン・ボリューム

基準テンポに対して様々な細分化グリッドのガイド音を個別に重ねられるミキサーです。各スライダーを左端（-40dB）にするとミュート、右に動かすほど大きくなります（最大+15dB）。数値ボックスへの直接入力も可能です。初期状態は全てミュートになっているので、練習に必要なものだけを選んで有効にしてください。

種類 リズムパターン
1拍に1回鳴る基本グリッド。テンポの骨格を確認したいときに。
1拍に2回。8分音符ラインを体感しながら練習できます。
1拍に4回。細かいグリッドのキープ力を鍛えます。
1拍を3等分。スウィングやトリプレットフィールの基礎に。
3連符の真ん中を休符にした跳ねるリズム（ダウン・休・アップの繰り返し）。ブルースやジャズのシャッフルビート練習に最適。
16分音符の内側2つを休符にしたリズム（ダウン・休・休・アップ）。付点8分＋16分の連続に近いグリッドで、軽快なスキップ感覚を体感できます。

各種類の音程・音色はスライダー下のセレクトボックスで変更できます。また、リズムトラック側の「クリック」セレクトボックスでいずれかを選ぶと、そのトラックの音量に連動したクリック音としてもご利用いただけます。

5. ランダム・テンポ変化設定

練習中に自動でテンポを変化させ、テンポキープ力・対応力を鍛えるモードです。

  • ランダム変化モード ON/OFF：スイッチで有効化。再生中でも即座に切り替えられます。
  • 変化の間隔：何小節ごとにテンポを変えるかを選択（1・2・4・8小節）。トラック1の1拍目がトリガーとなります。
  • 最大変化幅：1回の変化量の上限を設定。プラス方向（徐々に速くなる）またはマイナス方向（徐々に遅くなる）を選べます。変化量は1〜上限値の間でランダムです。
6. ビジュアライザーとオートセーブ
ビジュアライザー

各トラックの現在の拍位置がリアルタイムで色付き点灯します。シアンが表（ダウン拍）、マゼンタが裏拍です。拍数が多い場合は複数行に自動折り返しされます。

振り子バー

各トラックのビジュアライザー全体に表拍のたびに左右に振れる縦バーを表示します。トラック設定の「振り子」セレクトで色を選択（なし・白・シアン・マゼンタ・イエロー・オレンジ・ティール・ブルー）。再生開始時に左端からスタートし、以降テンポに合わせて等速で往復します。

自動保存

トラック設定・同期モード・サブディビジョン設定（音程・音色・音量）・マスターボリューム・ランダムテンポ設定は変更のたびにブラウザの localStorage へ自動保存されます。次回同じブラウザで開いたとき、前回の状態から再開できます。
